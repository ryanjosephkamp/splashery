# Codex task 78d: Your name in splats

From a concept by Ryan Kamp. Made by Ryan with Codex (GPT-6). Original procedural shapes and these
review images are CC0; recipe code on `codex/portfolio-d` is MIT.

This branch contains review clips only. Never merge it into the site.

Each clip was generated with `tools/effect-clip.mjs`: 320 × 320 pixels, 12 frames per second, and a
3.6-second effect. The tool steps the animation clock to show the effect's timing; these clips do
not measure a real phone's frame rate and do not contain audio.

- [Spin](spin.gif): the solid letters turn once and settle.
- [Poke](poke.gif): the letters recoil and settle.
- [Paint](paint.gif): tapping R paints it pink and gives it a bounce; the color stays.
- [Drop](drop.gif): the letters fall, bounce, and return to their rows.
- [Blow](blow.gif): a gust moves and tilts the letters, then they come home.

The adjacent `*-strip.png` files show eight frames of each effect.
