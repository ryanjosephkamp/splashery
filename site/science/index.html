The data behind the toys

Some toys show published data: each splat is a real measurement, or a real structure. This is where each comes from.

Toy What it shows Source License Evidence
Thermal ellipsoids How each atom in a crystal or protein jiggles, as a soft ellipsoid: the measured size and direction of its vibration. Crystallography Open Database
RCSB Protein Data Bank 		Public domain (COD)
CC0 1.0 (PDB) 		not written yet
Super-resolution microscope Single-molecule localization microscopy: the positions of hundreds of thousands of molecules inside a cell, measured to a few nanometers. ShareLoc.XYZ (Zenodo) CC BY 4.0 not written yet
Galaxy in a box Gas in a simulated Milky Way-like galaxy: 300,000 of the simulation's 2.37 million gas particles. FIRE-2 simulations, m12i (FlatHUB) CC BY 4.0 not written yet
Walnut CT scan, How CT works A real X-ray CT scan of a walnut (100 µm voxels), cut open slice by slice. Cone-beam CT data collection, CWI Amsterdam (Zenodo) CC BY 4.0 not written yet
Protein, DNA Real protein and DNA structures: ubiquitin, insulin, green fluorescent protein, hemoglobin and the B-DNA double helix. RCSB Protein Data Bank CC0 1.0 not written yet
Atom, Periodic table, Molecule All 118 elements (mass, electron configuration, spectral color), and molecules from water to caffeine. NIST atomic data
PubChem
IUPAC periodic table 		Public data; PubChem conformers are public domain not written yet
Word vectors 24,000 real English words placed by meaning, from the GloVe word vectors. GloVe, Stanford NLP PDDL 1.0 Evidence
Convolutional network A small network that reads the digit you draw, trained on real handwritten digits. Handwritten digits, UCI Machine Learning Repository CC BY 4.0 Evidence

The other science toys are built from recipes written for Splashery; each toy's About tab, in the gallery, says what it simplifies. Every credit and license, in full, is on the credits page. Evidence is written for 47 toys so far.

Is it right?

Every toy that claims to show something true about the world is meant to have an evidence file: what it claims, how the code does it, the sources, and where it simplifies. How they work is written up in the evidence guide, and each toy's own page shows its file.
