Sorting machine

Tap it to sort. Hands-on: pick a piece up and drop it on another place to swap them.

Tap
A row of colored bars of different heights sorts itself, the bars swapping as solid pieces, by bubble sort, quicksort or merge sort (an option), with a swap counter; then it shuffles again (5 s).
Sound
Each algorithm has its own voice: every comparison plays the two compared bars' notes softly, every swap the moving bar's note, each timed to its step; then the sorted bars play their scale.

About this toy

A sorting algorithm is a step-by-step recipe a computer follows to put things in order. Bubble sort keeps swapping neighbors that are the wrong way around; quicksort picks one item and splits the rest into smaller and bigger piles; merge sort sorts small groups, then merges them. On a long list, some need far fewer steps than others.

Tap it: eight bars sort themselves, each gliding to its new place, while a counter counts the swaps, or moves for merge sort; then they shuffle back. Pick one of eight algorithms in the Toy tab. Listen too: each comparison plays the two bars' notes softly, each swap the moving bar's note, every algorithm on its own instrument, so you hear how it works. The View option shows the same steps as crates of different sizes, a ring of colored pucks that sorts into a color wheel, or the classic dots. The steps come from each algorithm's real code, checked step by step against separate reference code. With ✋ Hands-on on, drop a piece on another place and the two swap.

Is it right?

All eight implementations match independent comparison and array-change traces. The display counts swaps, except that merge sort counts single-item moves. The bar animation omits comparisons that do not change the array. Checked October 4, 2026.

  1. Correct Bubble sort compares adjacent items in shrinking passes.

    It runs all shrinking passes, including any pass with no swaps.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Bubble sort, NIST Dictionary of Algorithms and Data Structures: Bubble sort compares neighboring items and exchanges items that are out of order.

  2. Correct Quicksort uses the Lomuto partition.

    The last item is the pivot, values strictly below it move left, self-swaps are omitted, and left partitions run first.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Quicksort, Sedgewick and Wayne, Princeton Algorithms: Quicksort partitions around a pivot and recursively sorts the resulting subarrays.

  3. Correct Merge sort combines runs bottom up and stably.

    Runs double in size. Equal values stay left; each needed right item is moved ahead of a left item.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Mergesort, Sedgewick and Wayne, Princeton Algorithms: Bottom-up mergesort combines adjacent sorted runs of increasing size; merge ordering can be stable.

  4. Correct Insertion sort moves each new value into the sorted prefix.

    Adjacent swaps move the value left until it is in order.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Insertion sort, NIST Dictionary of Algorithms and Data Structures: Insertion sort inserts each item into the sorted prefix; an adjacent-swap version is also described.

  5. Correct Selection sort selects the minimum of each remaining suffix.

    It exchanges the selected minimum with the current destination, omitting self-swaps.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Selection sort, NIST Dictionary of Algorithms and Data Structures: Selection sort repeatedly selects the smallest remaining item and moves it into place.

  6. Correct Cocktail sort alternates forward and backward sweeps.

    Both sweeps shrink the active bounds and compare neighboring values.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Bidirectional bubble sort, NIST Dictionary of Algorithms and Data Structures: Bidirectional bubble sort alternates forward and backward sweeps of adjacent comparisons.

  7. Correct Shell sort uses gaps 4, 2, 1.

    Each gap performs insertion by exchanges within the interleaved subsequences.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Shell sort, NIST Dictionary of Algorithms and Data Structures: Shell sort sorts interleaved subsequences at decreasing gaps, ending with gap one.

  8. Correct Heap sort builds and drains a max heap.

    Heap construction starts from the last parent and repeated extraction moves the maximum to the sorted suffix.

    All comparison values/operators and every array snapshot match the independent reference on 384 inputs.

    • Priority queues and heapsort, Sedgewick and Wayne, Princeton Algorithms: Heapsort builds a heap and repeatedly removes the maximum into the end of the array.

  9. Correct The counter counts swaps or merge moves.

    For every recorded stage of all eight default traces, the seven-segment display shows the stage count and uses MOVES for merge, SWAPS otherwise.

    • Mergesort, Sedgewick and Wayne, Princeton Algorithms: Bottom-up mergesort combines adjacent sorted runs of increasing size; merge ordering can be stable.
    • Bubble sort, NIST Dictionary of Algorithms and Data Structures: Bubble sort compares neighboring items and exchanges items that are out of order.

  10. Simplified Animated bar movements show only the exchanges or moves.

    Only changed arrays are saved; comparisons with no array change have no visible step. Merge insertion is one move, not a count of every write.

    The counter is not total running time, comparison count, or a fair memory-write benchmark across algorithms.

    • Mergesort, Sedgewick and Wayne, Princeton Algorithms: Bottom-up mergesort combines adjacent sorted runs of increasing size; merge ordering can be stable.
    • Bubble sort, NIST Dictionary of Algorithms and Data Structures: Bubble sort compares neighboring items and exchanges items that are out of order.

Where it simplifies

  • There are eight fixed bars in the picture. Comparison-only work is invisible. Merge counts one insertion move even when that move rewrites several array slots, so its counter is not comparable to a count of memory writes.
