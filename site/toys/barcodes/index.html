About this toy

Barcodes came before QR codes. Code 128 packs any plain text into bars and spaces one to four modules wide, with a check symbol worked out modulo 103. EAN-13 and UPC-A hold the numbers on things in shops, with a check digit from weights of 3 and 1, and quiet zones of blank space either side.

Here those three are drawn by Splashery's own code, and Data Matrix and Aztec, two square codes of their own, come from the open-source ZXing library. Tap to sweep a scanner's red line across. The toy reads its own picture back to check that it scans.

Is it right?

Code 128, EAN-13 and UPC-A are drawn by Splashery's own code; their bar patterns, check digits and quiet zones match the published rules and worked examples, our bars match an independent encoder's bar for bar, and every symbol reads back in an independent reader. Data Matrix and Aztec come from the open-source ZXing for JavaScript library and read back in a second, independent reader. Checked October 6, 2026.

  1. Correct Code 128's check symbol is the start value plus each symbol's value times its position, modulo 103.

    The encoder sums the start value and each value times its place and takes the remainder by 103; the test reproduces Wikipedia's worked example (PJJ123C in code set A gives 54) and a code set C example.

    Code 128 is defined in ISO/IEC 15417:2007, which is not freely readable; the rules here are as Wikipedia states them, and the bars are checked against BWIPP's encoder.

    • Code 128, Wikipedia: The check digit is a weighted modulo-103 checksum, the start code's value plus each symbol's value times its position; for PJJ123C in Code 128A the value 54 (a V) is appended.

  2. Correct Code 128's 107 patterns are each six bars and spaces adding up to 11 modules, and the stop pattern seven adding up to 13; start B is 211214 and the stop 2331112.

    The table holds each pattern's widths; the test checks every sum, that all 107 differ, and that whole symbols equal BWIPP's (bwip-js) bar widths where the choice of code sets has one obvious form.

    Two texts encode differently from BWIPP (12345 and a text with a tab): both choices are valid and both read back; the toy picks code sets by a simple rule (code set C for runs of four or more digits at the ends, six or more in the middle).

    • Code 128, Wikipedia: Start Code B is 11010010000 (widths 211214); the stop pattern is 1100011101011 (widths 2331112).

  3. Correct Code 128 needs a quiet zone of at least 10 modules on each side.

    Every Code 128 symbol gets 10 blank modules either side.

    • Code 128, Wikipedia: The minimum width of the quiet zone to the left and right of the Code 128 is 10x, where x is the minimum width of a module.

  4. Correct The EAN-13 and UPC-A check digit makes the weighted sum (weights 3 and 1, from the right) a multiple of 10.

    gs1Check weights the digits 3, 1, 3, … from the right and returns what brings the sum to a multiple of 10; the test reproduces Wikipedia's worked examples (400638133393 gives 1; UPC-A 03600029145 gives 2; ISBN 978-0-306-40615 gives 7) and rejects a wrong check digit.

    • International Article Number, Wikipedia: The checksum is a sum of products, alternating weights 3 or 1 times each data digit; the check digit brings it to a multiple of 10. For 400638133393x: 90 - 89 = 1.
    • Universal Product Code, Wikipedia: For 03600029145x: odd positions 14 × 3 = 42, plus even positions 16, is 58; 58 mod 10 = 8; the check digit is 10 − 8 = 2.
    • ISBN, Wikipedia: Thus, the check digit is 7, and the complete sequence is ISBN 978-0-306-40615-7.

  5. Correct EAN-13 encodes its first digit in the pattern of L and G codes of the left half, then six R codes, between guard bars 101, 01010 and 101: 95 modules.

    eanBits builds the 95 modules from the L, G and R tables and the first digit's parity pattern; the test checks the bars equal BWIPP's for three numbers and that zxing-cpp reads them back.

    • International Article Number, Wikipedia: Tables of the L, G and R codes for digits 0 to 9, and of the first digit's parity patterns, LLLLLL to LGGLGL.

  6. Correct A UPC-A code is an EAN-13 code with a leading 0, and needs a quiet zone of at least 9 modules each side.

    upcA encodes 0 followed by its 12 digits as EAN-13 and adds 9 blank modules either side; the test checks its bars equal BWIPP's UPC-A bars.

    • Universal Product Code, Wikipedia: Every UPC-A code can be easily converted to the equivalent EAN-13 code by prepending 0 digit to the UPC-A code. A quiet zone, with a width of at least 9 times the x-dimension, must be present on each side.

  7. Not yet checked EAN-13 needs a quiet zone of 11 modules on the left and 7 on the right.

    ean13 adds 11 blank modules before the symbol and 7 after it.

    These are the GS1 General Specifications' figures as commonly cited, but on October 6, 2026 GS1's own pages refused our reads (HTTP 403), and Wikipedia's EAN article and BWIPP's notes don't state them. The symbols read back in zxing-cpp with them.

  8. Close The default numbers are not any real product's: EAN-13 2001234567893 and UPC-A 401234567893 are in ranges kept for a store's own use.

    The defaults start with 200 (EAN-13) and number system 4 (UPC-A).

    The page we read names 020-029 for internal use; the EAN-13 default's 200 prefix is in the range GS1 keeps for restricted circulation as commonly cited, not confirmed on GS1's own page (which refused our reads).

    • Universal Product Code, Wikipedia: Number system 4: reserved for local use (store/warehouse), often for loyalty cards or store coupons.
    • International Article Number, Wikipedia: GS1 defines the prefixes 020-029 as being available for retailer internal use.

  9. Correct The Data Matrix and Aztec symbols are real and readable.

    They come from ZXing for JavaScript's DataMatrixWriter and AztecCodeWriter (Data Matrix forced square); the tests read them back with zxing-cpp, an independent implementation, and the toy reads its own picture with zxing-js.

    The browser test reads every kind back from the stage: tests/qrc-barcodes.spec.mjs:132.

    • ZXing for JavaScript, GitHub, zxing-js: A barcode scanning library in TypeScript, ported from ZXing, with Data Matrix and Aztec support.

Where it simplifies

  • The human-readable line under Code 128 uses Splashery's small 5 × 7 bitmap letters; characters the font lacks show as a middle dot (the bars still hold them).
  • The toy draws EAN-13 and UPC-A bars 60 modules tall and the digits in the usual places; the exact printed heights and the OCR-B type of real labels are not copied.
