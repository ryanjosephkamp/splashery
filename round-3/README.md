# Moving photo round 4: phone comparisons

These silent films visit every original file timestamp, or every retained JPEG-sheet sample frame,
at the same camera. Video pictures are native. GIFs keep the app's profile frame budget and can hold
a retained composite across original timestamps. These compare picture quality; separate live timing
ledgers measure playback speed. Round 3 receives the exact chosen native video picture for this
geometry comparison. Long films use the baseline's actual local-file path only when absent from its
shelf; each card records its path.

Each individual film is 390 × 844. Side-by-side films preserve that size in each column (780 × 844
overall). [Open the gallery](index.html). [The manifest](manifest.json) records input hashes,
authors, licenses, changes, output hashes, and precise source clocks. One repeated end frame
preserves the final source frame's whole hold; encoded durations differ from source durations by
less than one millisecond.
