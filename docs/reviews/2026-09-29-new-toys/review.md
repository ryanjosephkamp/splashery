> # splashery-new-toy-reviews-2026-09-29.md

> ## "Pictures and pages":
>
> Overall, I'm very impressed. Here are the main items to change or improve.
>
> "Picture lab":
>
> - Clicking/tapping on left of page should go back a page, and clicking/tapping on right of page
>   should go forward; I suppose that a click exactly in the middle can also go forwards, etc.
> - For the picture lab, I like that the pages don't flip like a real book; that happens for the
>   book and photo album toys.
> - The background rectangle is a bit grainy, especially around the edges, so we could make that
>   sharper.
>
> "Your book":
>
> - For the styles that flip horizontally (i.e., not stapled paper): clicking/tapping on a left page
>   should go back a page, and clicking/tapping on a right page should go forward; I suppose that a
>   click exactly in the middle can also go forward, etc.; clicking anywhere on front cover should
>   open the book, like it currently does.
> - For the styles that flip vertically (right now, this is only the stapled paper style):
>   clicking/tapping on a the top of a page (maybe in the top 25% of the page) should go back a
>   page, and clicking/tapping at or below that top region of a page should go forward; clicking
>   anywhere on front cover should open the book, like it currently does.
> - We need to improve the page turning animation. Currently, it feels unnatural and awkward, like
>   something incorrect happens before the page actually turns. Additionally, I'd like the user to
>   be able to drag on the book to turn a page, using realistic physics. Clicking a page is
>   different from grabbing and pulling it: a click without a drag should be an automatic page turn,
>   with the direction depending on where the user has clicked; a drag/pull of the page should peel
>   the page in a natural manner and require the user to actually move the page sufficiently far for
>   the page to turn, like a real physical book would. On a final page, advancing to the "next page"
>   should close the book like it currently does, etc.
> - The cover rectangles are grainy and not sharp enough.
>
> "Photo album":
>
> - For the styles that flip horizontally (i.e., not stapled paper): clicking/tapping on a left page
>   should go back a page, and clicking/tapping on a right page should go forward; I suppose that a
>   click exactly in the middle can also go forward, etc.; clicking anywhere on front cover should
>   open the book, like it currently does.
> - The page turning animation for the photo album is a bit better than that of "your book", and it
>   doesn't need much improvement. However, as for the "your book" toy, I'd like the user to be able
>   to drag on the book to turn a page, using realistic physics. Clicking a page is different from
>   grabbing and pulling it: a click without a drag should be an automatic page turn, with the
>   direction depending on where the user has clicked; a drag/pull of the page should peel the page
>   in a natural manner and require the user to actually move the page sufficiently far for the page

>   book does, so perhaps the manual drag/pull page turning can feel slightly slower or otherwise
>   subtly reflect that additional weight.
> - The cover rectangles are grainy and not sharp enough. Leather should look like real leather,
>   linen like real linen, etc.
