# Historical scene compatibility — October 2, 2026

Codex built a frozen 62-case corpus on `codex/compat-tests` from commits reachable from main. 17
cases copy saved Manual links or complete schema examples; 26 replay historical test inputs or
flows. The remaining 19 reconstruct historical defaults, enum values, the renamed clock, and option
value types. Every fixture records its full source commit, source path, method, saved hash, and
frozen expectations. Each case is exercised at `/`, `/embed/`, and through the real `#import-json`
Load JSON input. Coverage includes schema 2/3, both `d.`/`j.` formats, all 12 patterns, four
projections, all five moves, options, and v1 refusal. All 186 visitor checks passed, including the
expected v1 refusal, with no page errors. The final file took 22.8 seconds on this laptop. Only the
task's test, fixture directory, and this report were changed; no production code was changed.

## Method and limits

- Baseline: `2ec27c1568cdd496f6fc9d8416be8b5049ee4fe5`. `git log -p main` and path-specific logs
  covered tests, docs, fixtures, schema/codec changes, and toy ids/options, including merged side
  branches. All 12 source commits are ancestors of main; every recorded source path exists.
- Saved Manual links and the two schema examples are copied directly. Other cases reproduce
  historical literals, flows, or declared values using extracted historical modules. Only the
  nondeterministic seeds/timestamps in default/flow replays are pinned. The 19 supplemental
  reconstructions are labeled; no private visitor files were collected.
- Expectations and hashes are frozen in the fixtures. The test uses neither today's encoder nor
  today's normalizer for its oracle. Independent zlib/base64 decoding checks payload integrity.
  Visitor checks cover the built toy, all recognized saved recipe options, pattern application,
  motion/control state, look, effects, paint, camera, autoplay, seed, and page errors. Embeds use
  their intended 3.8/5 camera-distance multiplier. Distinct fixture queries force fresh startup;
  three separate browser contexts exercise both link routes and the real Load JSON input.
- The codec began with both `d.` and `j.` in `1a2dd3d6c8f14f11a1afd5766392e5d687f1ba46`. The v2
  change removed a PNG helper; the encoding/decoding functions stayed unchanged. No later
  hash-format change was found. Fixtures span the v1/v2/v3 schema boundaries with these two formats.
- `donut`, `planet`, and `crystal-ball` moved shelves in `da16abf415080cf7fd15b6644a14b80793644053`:
  Shapes to Food, Shapes to Space, and Gems to Medieval. Earlier donut/planet inputs and the later
  shelf test inputs are retained. The `alarm-clock` id also covers the display-name change to Real
  alarm clock in `ff639f4e758645d199e446d084dd3ef3275b568b`.
- Invalid inputs deliberately check historical normalization/fallbacks. Unknown numeric/boolean
  option keys check schema persistence; recognized options also reach the built recipe. This corpus
  omits own-device splat/media files, external media fetching, physical phones, Safari, Firefox, and
  WebGPU.
