Codex built this audit on October 3, 2026, against `main` at
`aba77089cd935f20358302a8ba8c7b39215b7f2d`. The ideal Gaussian math is sound; the connection to the
actual renderer needs more explanation. All three example modules build, and their four recipes
render with temporary catalog integration. All 15 gallery programs match their links and open
locally and on the public site. There are no broken manual links; all 34 image references load.
Twenty small factual correction groups are applied to the HTML and listed below. The checked-in PDF
has 33 pages and needs regeneration after these corrections. New sections, figure replacements,
recipe changes and PDF work remain proposals for a Claude lane.

| Glossary term                     | Proposed short definition                                                                                                          |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Gaussian / peak-one bell          | A smooth weight that decays exponentially with squared standardized distance; this manual uses peak 1.                             |
| Mean / center μ                   | The position where the bell has its maximum weight.                                                                                |
| Standard deviation / axis width s | A scale used to measure distance along one principal axis; it is not a hard radius.                                                |
| Covariance Σ                      | A symmetric matrix encoding squared widths and their orientation; cross terms tilt the axes.                                       |
| Anisotropic / isotropic           | Different widths along axes / equal widths in every direction.                                                                     |
| Quaternion q                      | Four constrained numbers representing rotation; it must be a unit quaternion.                                                      |
| Footprint                         | The projected region where one splat can contribute to screen pixels.                                                              |
| Jacobian J                        | The derivative of projection at the center, used as a local linear approximation.                                                  |
| Opacity α / transmittance T       | How much a footprint contributes / how much remains visible through nearer footprints.                                             |
| Alpha compositing                 | Ordered accumulation of color weighted by opacity and remaining visibility.                                                        |
| Spherical harmonics               | Directional color coefficients used by many trained captures; distinct from the kit's base RGB.                                    |
| Recipe / capture                  | A program that creates splats / stored splats fitted to observations.                                                              |
| u, v / t / morph                  | Parameter coordinates / phase or toy time, depending on API / interpolation to a target point.                                     |
| Kernel                            | The footprint's falloff rule; the renderer's finite bell and optional sharp kernel are approximations to distinguish from ideal G. |
