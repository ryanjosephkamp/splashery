# The Tinkerer's Manual: third audit

Codex audited main `0a358f98` on October 12, 2026. **48 findings: 0 high, 18 medium, and 30 low.**
Duplicates count once. All 75 gallery programs build and match their links; all 48 new-chapter toy
links pass. All 14 demos and three live/vector figures were captured at both requested sizes. The
148-page PDF is current and complete, with no localhost links. Current internal destinations
resolve; missing compatibility aliases and new-tab behavior remain. Four publisher challenges and
two GitHub server errors are recorded as source-access limits. Only this report and its 45 evidence
images are changed.

Read all 21 reading-order pages, the combined print page, the redirect stub, ManualR6, ManualR7a,
ManualR7b, ManualR7c, SiteR5, PACKS, and the implementation paths each page names. The checks below
cover claims, numbers, code, captions, glossary definitions, references, link behavior, and PDF
contents. Dated research measurements were compared with their recorded data, not treated as current
physical-device benchmarks.

High means a failure that blocks the core tutorial; medium means a wrong capability, implementation
explanation, or meaningful limit; low means a narrow qualification, caption, missing term, or small
numerical labeling issue. The covariance tolerance counterexample is low because it lies below the
normal demo sliders' resolution.
