# Still comparisons

These body-text images retain their native framebuffer crop pixels without resizing. All use repeat
1, rather than selecting the best run. Caption scores are three-repeat medians. The independent
reference was rendered at width 2,048 and sampled at the displayed pixel grid. The separate main and
round 2 reference crops are in the benchmark archive.

Whole-page images are JPEG review copies of repeat 1 of each toy's sample at 390×844 and 1440×900;
quantitative crops remain PNG. All images are below 1 MB. Recording and original comparison
contributions are CC0, made by Ryan with Codex (GPT-6); existing photo credits remain in CREDITS.md.
