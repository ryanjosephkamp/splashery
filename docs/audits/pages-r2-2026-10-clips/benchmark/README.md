# Matched benchmark evidence

118/144 planned fresh-browser cases; 19/24 groups have all three pairs. The raw
[main records](main.json) and [round 2 records](round2.json) retain every completed case. The
[comparison table](comparison.md) and [comparison checks](comparison.json) score only groups with
all three pairs. Renderer, fixture, tool, protocol, source commit, and runtime hashes are retained.
The [artifact manifest](artifacts.json) maps each case and repeat to its exact source and rendered
crop and their SHA-256 hashes.

See the implementation branch's
[audit](https://github.com/ryanjosephkamp/splashery/blob/codex/book-picture-lab-r2/docs/audits/pages-r2-2026-10.md)
for definitions, commands, exploratory exclusions, and limits. Copy the archived fixtures into
work/pages-r2/fixtures before reproducing the matrix. These are software-renderer browser
measurements, not physical-phone measurements. Stepped clips are separate motion evidence.
