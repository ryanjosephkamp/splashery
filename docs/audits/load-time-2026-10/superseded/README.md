# Superseded opening measurements

Every timing and payload observation in this folder predates the current review run. These records
are retained for traceability only. The sole current result table is in
[the audit](../../load-time-2026-10.md), with its five-pair observations in
[current-results.json](../current-results.json).

In particular, `review-timing.json` contains the earlier mixed-session Sunglasses observations. They
are not pooled with the current session. The original catalog summaries, screening, renderer
controls, and paired follow-ups also remain historical.
