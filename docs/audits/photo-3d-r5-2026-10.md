## Target selection and correction

The [118-input atlas](photo-3d-failures-2026-10.md) supplies the frozen source hashes, nine poses,
two profiles, probes, metric definitions, and review levels. A row is one input at one profile. For
each class, cost is the flagged row count times its mean severity, where severity is the row's worst
supported pose score divided by that class's existing review level. Equivalently, cost is the sum of
these ratios over flagged rows. This is a repair-priority heuristic, not a perceptually calibrated
comparison between unlike units. The initial ranking omitted the atlas's separate flat-depth warning
filter. Including that filter corrects the three highest costs as follows. This correction does not
move the original deadline; no production reconstruction change was retained under the initial
selection.

| Class                                | Flagged / supported rows |        Mean flagged score |     Cost | Intended repair                                                                                                                        |
| ------------------------------------ | -----------------------: | ------------------------: | -------: | -------------------------------------------------------------------------------------------------------------------------------------- |
| Color error at depth boundaries      |                227 / 227 |        13.4661% RGB error | 764.2023 | Inspect source-color ownership and depth-edge registration; preserve text, thin structures, and probe support.                         |
| Flat-depth T-junction warnings       |                209 / 212 | 56.0372% warned junctions | 585.5884 | Investigate source-supported depth separation with frozen baseline probes; texture junctions alone cannot justify new geometric steps. |
| Directional ribbons in revealed fill |                211 / 223 | 40.3048 percentage points | 566.9536 | Continue eligible background texture into disocclusions while preserving gradients and believable content.                             |

The remaining costs are texture-energy loss 232.1019, fringe width 195.4848, lost thin-line contrast
173.5949, memory 138.8500, depth-order warnings 124.1080, cold latency 53.3361, and zero flagged
holes or default-threshold reference-depth errors. The exploratory 5% reference-depth cutoff has a
cost of 20.1228 and does not affect the selected targets. Flat-depth and order warnings are
image-cue hypotheses, not measurements of physical scene depth. Reference errors remain separate.
Unsupported scores remain unknown. Both profiles and every input remain regression gates.

The atlas examples include the dog's muzzle and ears, the dragonfly, and the long library for
boundary error; submerged stones, the frozen waterfall, and the fishing cove for flat-depth
warnings; and the forest path, the still-life painting, and the tabby for ribbons. The exact flagged
membership and scores are recorded in [the target manifest](photo-3d-r5/targets.json).

## Verification plan

Re-measure frozen main with the original finder, measure repeat noise, and compare candidates using
the same input hashes and native rendered evidence. Reject any supported per-input regression, lost
probe support, blank capture, changed test threshold, or phone cost increase. Keep metric
calibration separate from visual review. Phone-profile software rendering is not a measurement on a
physical phone. The final handback will distinguish completed checks from missing evidence.
