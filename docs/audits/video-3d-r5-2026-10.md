## Changes measured so far

Graphics-adapter discovery now has a ten-second deadline and honors cancellation before requesting
an adapter and while waiting for one. Previously, an unresponsive `requestAdapter()` could prevent
the toy from reaching training or explaining a failure indefinitely. Both the progress-card check
and the pipeline pass their operation's cancellation signal. A late adapter response cannot replace
the deadline result. This does not create a graphics device or alter Gaussian training.

Surface initialization retains only the nearest eight candidates while visiting the same spatial
cells. The original triangle search reads only those eight. The bounded search preserves stable
ordering at equal distances and avoids copying and sorting the discarded neighbors. On the original
614-point, 16-camera chameleon cache, all output parameter bytes, counts, and support counts match
the previous initializer across three settings and six alternating-order repetitions. The phone seed
setting's observed median initialization time was 346.55 to 240.55 milliseconds. The 30,000-point
setting was 617.02 to 630.15 milliseconds, so this diagnostic establishes no general speedup. These
are CPU initialization diagnostics under concurrent host work, not native bake or physical-phone
performance measurements.

The camera-solve retry now requests three cameras before the session accepts a reconstruction.
Previously, a two-camera result could resample the training RGB for its estimated distortion and
release low-memory grayscale pictures before the video pipeline rejected it. The relaxed retry then
received missing feature pictures. The opt-in `minCameras` guard runs before either mutation.
Sessions that omit it retain their existing two-view behavior. The engine change has its own
`Engine:` commit. Real-session controls simulate only the solver result; they verify preservation of
original picture references and pixels, rejection of invalid minima before solving, legacy two-view
acceptance, release after an accepted three-view solve, and the actual pipeline retry.

The cached chameleon photographs and reconstructed geometry retain Ventrovert's CC BY 4.0 credit and
the original source and transformation record. No sample bake, scene coordinate rule, photometric
threshold, training setting, iteration budget, or image scoring formula changes here.
