# Splashery backlog

Things that were asked for or planned but are not being built now. Each one says why and what would
unblock it. The plan they belong to is in [ROADMAP.md](ROADMAP.md).

| Item                                                       | Why not now                                                                                                                                                                           | What would unblock it                                                                                                                                  |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Gallery of the best toys                                   | Deferred by the owner until the packs land. The plan is in ROADMAP.md.                                                                                                                | The owner saying "build the gallery".                                                                                                                  |
| Homepage embed                                             | Deferred by the owner.                                                                                                                                                                | The owner saying so; the `<splashery-toy>` element already works on the personal site's theme events.                                                  |
| True liquid simulation                                     | Particle fluids want WebGPU compute and a WebGL2 fallback; a scripted pour (tilt keeps the surface level, then it pours and pools) comes first.                                       | Time after the packs; a WebGPU-only "experimental" toggle.                                                                                             |
| Multi-toy scenes and toy-on-toy physics                    | Needs a scene schema with several toys and a floor, and a small rigid-body step.                                                                                                      | After schema v3 settles; Rapier (Apache-2.0, vendorable WASM) only if stacking many bodies becomes a feature.                                          |
| 4D Gaussian splat captures                                 | No standard format in PlayCanvas, very large files, and built-in behaviours already make toys feel alive.                                                                             | A small open 4D capture (for example a candle flame) to try as a flipbook of SOG frames.                                                               |
| AI image-to-3D toys                                        | Needs a Hugging Face token at build time; none is set in the cloud environment yet.                                                                                                   | The owner adds `HF_TOKEN` as an environment variable in the Claude Code cloud environment settings (easier on the web or desktop app than on a phone). |
| More scans: Kitty, Lioness (Panthera Spelaea)              | Both are CC BY on SuperSplat but only published as streamed SOG ("ssog"), which the public data URL refuses (403).                                                                    | The authors enabling a plain SOG or PLY download, or a SuperSplat API for streamed scenes.                                                             |
| Stagecoach scan                                            | Listed as CC BY, but its scene data returns 403.                                                                                                                                      | The author re-publishing it with downloads enabled.                                                                                                    |
| The Moon and Stonehenge scans                              | Both CC BY and converted, but blurry and washed out at toy size, so they were left off the shelf.                                                                                     | Sharper captures, or a crop tool that keeps only the well-covered part.                                                                                |
| Smithsonian 3D models (CC0)                                | The Smithsonian 3D site did not respond from the build environment.                                                                                                                   | Retrying `tools/mesh-to-splats.mjs` with a Smithsonian source when the site is reachable.                                                              |
| NASA 3D models                                             | Many carry mission insignia or logos, which NASA's media guidelines restrict. The procedural space pack covers the shapes.                                                            | Picking models with no insignia, checked one by one.                                                                                                   |
| More music toys (piano, trumpet, violin, maracas and more) | The builder stopped at a usage limit after the guitar, drum and xylophone.                                                                                                            | A follow-up pack PR.                                                                                                                                   |
| Skull and hand skeleton                                    | Skipped in the body pack to keep it friendly (skull) and for time (hand).                                                                                                             | The owner asking for them.                                                                                                                             |
| Clean draw order for big moving parts                      | Splats are depth-sorted in their built pose, so large part movements (storybook cover, DNA unzip) can draw in the wrong order. Two toys build their moving lid twice as a workaround. | Re-sorting per part on the GPU, or PlayCanvas exposing a per-frame sort hook for work-buffer changes.                                                  |
| Flag of Oman                                               | The Commons file is under Oman's Open Government Licence (OGL-om 1.0), which is not CC0, CC BY or public domain.                                                                      | The owner approving that licence, or a public-domain redraw appearing on Commons.                                                                      |
