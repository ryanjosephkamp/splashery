# Picture QR review · Codex (GPT-6)

Study and review renders made by Ryan with Codex (GPT-6). Source picture credits remain in
[CREDITS](../../../CREDITS.md).

This branch is for review pictures and clips and is never merged. Each page below shows native
390×844 before-and-after pairs in Square and Circle, using the first fixed payload. Scores average
all ten payloads. The code and full audit are on `codex/picture-qr-fidelity`. Open `index.html`
through the repository’s local server for the complete gallery.
