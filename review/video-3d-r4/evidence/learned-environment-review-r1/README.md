The simple three-scalar least-squares solution is mathematically valid for current Video3D's unmasked, unit-gain/zero-bias, native-resolution renderer. Let raw black RGB be C0, raw transmittance T=1-opacity, packed RGB target Y. Fixed-model error is C0+T*B-Y. For each RGB channel independently, D=sumT^2, Q=sumT*(Y-C0), S=sum(Y-C0)^2, and B=clamp(Q/D,0,1). The objective is D*B^2-2Q*B+S; black (or any existing in-range constant) is feasible, so this constrained optimum cannot increase that exact fixed-model aggregate packed-target MSE. It adds only three shared numbers, no image detail, depth, camera, crop, texture card, or spatial color map. Spatial change remains constrained by the already-learned T. MSE nonincrease is neither Charbonnier/SSIM monotonicity nor proof of a better exported view.
